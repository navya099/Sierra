# v12.5.2-A 교량 경계 보정

- 교량 후보 판정은 기존과 동일: 연속 성토 구간 길이 >= 100m, 최대 성토고 >= 15m.
- 실제 AUTO 교량 구간은 성토고 >= max(bridge_start_fill_h, girder_top_offset + girder_h)로 잘라냅니다.
- bridge_start_fill_h 기본값은 5m이며 구조물 관리 GUI에서 조정 가능합니다.
- 경계 측점은 선형 및 지반의 차이와 임계값의 교차점을 이분법으로 계산합니다.
- 임계값 이상인 연속 구간이 여러 개라면 분리합니다. 보정 후 100m 미만인 구간은 제외합니다.
- MANUAL 구조물 및 CSV 로드 구조물은 자동 보정하지 않습니다.
- 수정 전 후보 CSV를 불러왔다면 GUI의 '자동 후보 생성'을 다시 눌러 새 측점을 적용하세요. 기존 목록 교체 전 CSV 백업 권장.
- 기존 BRIDGE_GIRDER 레이어 및 분할 출력 로직은 변경하지 않았습니다.
- 도면상 개략 거더 배치 규칙이며 교대·기초 설계 검토를 대체하지 않습니다.
