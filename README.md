# 종곡선 엔진 v12.3.1 — GUI 입력 및 계산 비교

기반: 승인된 v12.2 GUI/도면 출력 + v12.3 대칭 포물선 종곡선 계산 엔진.

## 신규 GUI
- `종곡선 설계 (시험)` 탭에서 내부 VIP 선택 → L(m) 입력 → `길이 적용`
- L=0이면 종곡선 지정 해제; BP/EP에는 길이를 지정할 수 없음
- PVC/PVT, 접선 교점 표고와 종곡선 중심 표고 및 차이 표시
- `종곡선 계산`, `계산 결과 CSV 저장` 제공
- 원본 DXF 저장·수정 없음; CAD에서 재분석할 때 측점이 동일한 VIP의 길이 설정은 유지
- **중요:** v12.2 종평면도 및 최종 평면도 출력은 승인된 상태로 유지. 종곡선 형상을 도면에 반영하는 기능은 아직 미구현.
- **주의:** 종곡선 길이 설정은 현재 실행 중 메모리에만 보관되며 프로그램 재시작 시 복원되지 않음.

## 실행
`python main_gui.py`

- 인접 VIP 범위 초과 및 종곡선 간 중첩은 거부.
