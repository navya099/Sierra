# v12.5.2-A — 교량 거더 종단 표현

- GUI 구조물 관리 탭에 거더 높이, 기준 경간, 상단 이격, 샘플 간격 입력 추가.
- 구조물 목록의 BRIDGE만 사용. TUNNEL 제외. 이름 T1/B1 규칙 유지.
- 각 교량을 기준 경간 이하의 균등 경간으로 분할. 경간 경계는 전체 노선 기준으로 고정.
- 계획고(출력 옵션에서 활성화한 종곡선 포함) 아래 top_offset, girder_h 적용.
- BRIDGE_GIRDER 레이어에 경간별 닫힌 LWPOLYLINE 작성.
- 독립 종단 DXF 분할 시 구간 및 Datum 변경점에서 잘라 그림.
- **개략 종단 표시**이며 실제 거더 구조 설계/교각/교대는 후속 단계.
- 원본 DXF는 읽기 전용; 출력은 별도 파일.
- 주의: 종곡선 DXF 적용 체크박스가 OFF면 거더도 직선 계획고를 따름. 구조물 자동 후보 재생성은 별도 실행.
